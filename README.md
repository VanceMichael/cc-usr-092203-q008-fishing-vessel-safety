# 渔船出海安全闭环

把渔船离港前检查、缺陷整改和航行联系形成安全闭环。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料反映以下领域事实：

- 船舶证照、船员清单、海况预报、动力检查、通信测试、救生衣与救生筏状态、缺陷整改和离港许可共同构成一次出海的完整档案
- 检查照片与仪器结果必须带采集时间，超过有效期的证据不能用于放行
- 复检只能在历史记录上追加结论，既有检查结果不可改写
- 船员临时更换、设备借用、预报升级、跨港转场和系统断网都不能绕过未关闭缺陷
- 多部门对同一项目的重复检查归并为一条结论，但各部门责任各自保留
- 船主在离港前能看到阻断离港的具体事项清单，值班员只在证据齐全后签发离港许可
- 航行期间失联或偏离计划航线会自动进入联系与升级流程，返港后的实际事件用于反向改进检查规则

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、事实和约束均保持完整。仓库不保存账号、密钥、连接串或真实身份资料。
