# 渔船出海安全闭环

把渔船离港前检查、缺陷整改和航行联系形成安全闭环。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料覆盖出海安全闭环：

- **保存资料**：船舶证照、船员清单、海况预报、动力检查、通信测试、救生衣与救生筏状态、缺陷整改与复检、离港许可；检查照片与仪器结果带采集时间
- **缺陷不可绕过**：船员临时更换、设备借用、预报升级、跨港转场、系统断网离线均不能绕过未关闭缺陷，复检只能追加结论
- **检查归并**：多部门重复检查归并为同一检查事件，但按部门和检查员保留责任
- **放行**：船主提前看到阻断离港的具体事项，值班员只在证据齐全后放行
- **航行与返港**：失联或偏离计划自动进入联系与逐级升级；返港后以实际事件反向改进检查规则

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、闭环资料类别、阻断场景、约束和升级规则均保持完整。仓库不保存账号、密钥、连接串或真实身份资料。
